# Modelo Piloto · Restaurante Maderos

Presentar **Modelo Piloto.bpmn**. El general sigue la estructura del As-Is: recepción, decisión de ubicación, atención y cierre, y acondicionamiento de mesa. PIL06 detalla la atención, incluida la comanda digital y las excepciones. PIL07 detalla recepción y espera, PIL08 el pago y los medios alternativos, y PIL09 el acondicionamiento de la mesa.

Cargar los diez archivos BPMN juntos en un proyecto llamado Modelo Piloto para tener todos los procesos llamados en el mismo espacio. Los archivos son descriptivos. El umbral de dos minutos sin acuse constituye una decisión propuesta para validar antes de operar el piloto. Trazabilidad.csv vincula las actividades del perfil con el diseño.
